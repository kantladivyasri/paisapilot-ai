# Nidhi Pilot AI — Intelligent Personal Finance Planning Agent

> **Understand Your Money. Plan Your Future.**

Nidhi Pilot AI is a full-stack, hackathon-ready intelligent personal financial planning web application tailored for Indian students, salaried professionals, and individuals seeking financial clarity. It converts raw income/expense transactions into structured financial insights, deterministic budgeting plans, savings targets, and interactive AI assistance.

---

## 🌟 Key Highlights & Features

1. **Production-Grade Backend with Persistent Credentials:**
   - **Database Durability:** SQLite configured with Write-Ahead Logging (`PRAGMA journal_mode=WAL`), foreign key enforcement, and busy timeout handlers for concurrency.
   - **Persistent Configuration:** API keys configured in the UI or `.env` are safely saved to `backend/.env` and persist across server restarts.
   - **Dual Real LLM Providers:** Supports **Groq Cloud API** (`llama-3.3-70b-versatile`, `llama-3.1-8b-instant`) and **Google Gemini API** (`gemini-2.0-flash`, `gemini-1.5-flash`), with graceful fallback to the deterministic engine if offline.

2. **Real Chat LLM with Deep Financial Grounding (No Generic Answers):**
   - Injects the user's live database figures (exact income, expenses, cash surplus, essential vs. discretionary split, category sums, active budget limits, and savings goals) into the system prompt.
   - Explicit instructions for step-by-step mathematical reasoning: shows the exact equation, remaining cash buffer, and change in savings rate.
   - Differentiates between non-negotiable essentials (Rent, Groceries) and discretionary lifestyle expenses (Swiggy/Zomato, Shopping) to provide tailored Indian financial advice.

3. **Dashboard & Financial KPIs (INR ₹ Formatting):**
   - Live metrics: Total Income, Total Expenses, Available Balance (Surplus/Deficit), and Savings Rate (`(Income - Expenses) / Income * 100`).
   - Interactive visual breakdown by category using **Recharts Donut Chart**.
   - Monthly cash flow trajectory with gradient **Area Charts**.
   - Active savings goals snapshot and proactive financial alerts.

2. **Transaction Management & CSV Statement Import:**
   - Add, edit, and delete transactions with instant balance recalculation and confirmation dialogs.
   - Categorization for Indian digital spending (UPI, Swiggy, Zomato, Rent, Blinkit, D-Mart, Electricity, Education fees, etc.).
   - Multi-column CSV import engine with flexible header normalization (`Narration`, `Debit`, `Credit`, `Particulars`, `Amt`, `Date`).
   - **Duplicate Detection:** Alerts users of potential duplicate transactions without silently discarding records.

3. **AI Spending Analysis:**
   - Deterministic split between **Essential Obligations** (Rent, Groceries, Electricity, Healthcare, Education) and **Discretionary Spending** (Dining, Shopping, Entertainment).
   - Largest expense drivers ranked with percentage breakdowns.
   - Month-over-month trajectory (computed strictly when multi-month data exists; never fabricated).
   - Anomaly detection for outsized expenses and actionable savings recommendations.

4. **Personalized Budget Planner:**
   - Accounts for user circumstances: Monthly income, fixed essentials, variable essentials, and obligations.
   - **Mathematical Feasibility:** Enforces that proposed budgets balance. If essential expenses exceed income, it raises a clear shortfall notice with a **4-Phase Restructuring Recovery Plan** instead of an unfeasible budget.
   - Educational **50 / 30 / 20** benchmark comparison.
   - Category spending limit progress bars with over-budget alerts.

5. **Deterministic Savings Goals:**
   - Tracks target amount, current saved amount, target date, and planned monthly contributions.
   - Deterministic completion projection: `(Target - Current) / Monthly Contribution`.
   - **Feasibility Intelligence:** Compares planned contributions against the user's actual monthly surplus.

6. **Dual-Engine AI Finance Assistant:**
   - Conversational assistant grounded exclusively in real database figures.
   - **Groq LLM Integration:** Uses Groq (`llama-3.3-70b-versatile` or `llama-3.1-8b-instant`) with strict financial facts injected into the prompt.
   - **Deterministic Fallback Engine:** If no Groq API key is configured or network is offline, seamlessly operates using a 100% deterministic rule-based engine.
   - Visual badges on every response indicating whether it was generated by the Groq LLM or the deterministic engine.

## 🛠️ Technology Stack

- **Frontend:** React 18, Vite, Tailwind CSS, Lucide React icons, Recharts
- **Backend:** Python 3.10+, FastAPI, Pydantic v2, SQLAlchemy 2.0, Pandas
- **Database:** SQLite (local persistent storage: `paisapilot.db`)
- **LLM / AI:** Groq Cloud API (`llama-3.3-70b-versatile`) + Local Ollama support + Deterministic Engine Fallback
- **Testing:** Pytest, HTTPX, FastAPI TestClient

## 🚀 Quick Start Guide

### Prerequisites
- Node.js (v18+) and npm
- Python (v3.10+)

### 1. Backend Setup & Startup

```powershell
# Navigate to the backend directory
cd backend

# Create virtual environment (if not already created)
python -m venv .venv

# Activate virtual environment
# Windows PowerShell:
.\.venv\Scripts\Activate.ps1
# Windows Command Prompt:
.\.venv\Scripts\activate.bat
# Linux / macOS:
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# (Optional) Set your Groq API Key
# Copy .env.example to .env and configure GROQ_API_KEY
copy .env.example .env

# Run backend API server on port 8000
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
The FastAPI backend will be live at `http://localhost:8000` (API documentation at `http://localhost:8000/docs`).

### 2. Frontend Setup & Startup

```powershell
# Navigate to frontend directory in another terminal
cd frontend

# Install npm dependencies
npm install

# Start Vite dev server on port 5173
npm run dev
```
Open `http://localhost:5173` in your browser.

## 🔒 Financial Safety & Grounding Principles

1. **No Hallucinated Figures:** The AI Assistant uses verified structured metrics from SQLite. The LLM is instructed never to invent or alter numbers.
2. **Explicit Cash Flow Separation:** Inflow and Outflows are validated separately; amounts are strictly required to be positive numbers.
3. **Graceful Zero-Division:** Handles fresh zero-income states safely without crashes.
4. **No Unsolicited Speculation:** The application does not recommend speculative financial instruments or loans.
